# Selenide + Retrofit test framework

Java 21 / Gradle test automation for automationexercise.com (UI + API), restful-booker (API) and the-internet.herokuapp.com (UI).

- Rules and review checklist: `docs/BEST_PRACTICES.md`, the source of truth for how code here is written and reviewed.
- For reviewing, writing tests or page objects, adding APIs, or fixing flaky tests, use the `aqa-framework` skill.
- Commands: `./gradlew test` | `apiTest` | `uiTest` | `test --tests '*Name'` | `allureReport`.
- Mechanical checks: `python3 .claude/skills/aqa-framework/scripts/lint.py`.
